# Heap と Horreum

[English](heaps.md) | 日本語

## レシピ

| ブロック | 材料 |
|---|---|
| Item Heap | 鉄ブロック4個・ネザースター2個・ネザライトインゴット2個・チェスト1個 |
| Fluid Heap | 鉄ブロック4個・ネザースター2個・ネザライトインゴット2個・大釜1個 |
| Energy Heap | 鉄ブロック4個・ネザースター2個・ネザライトインゴット2個・レッドストーンブロック1個 |
| Gas Heap | 鉄ブロック4個・ネザースター2個・ネザライトインゴット2個・オスミウムブロック1個（Mekanism があるときだけ） |
| Horreum | ネザライトインゴット4個・ネザースター4個・空の Heap 1個（種類は問いません） |

Horreum の材料にできるのは、空の Heap だけです。

## 画面

Heap を右クリックすると画面が開きます。入っている物・バー・量と容量・2つのスロット（左が **In**、右が **Out**）が並びます。

| | Item Heap | Fluid・Energy・Gas Heap |
|---|---|---|
| **In** | アイテムを入れる | 容器を置くと、中身を Heap に移す |
| **Out** | アイテムを取り出す | 容器を置くと、Heap から中身を満たす |

Fluid・Energy・Gas Heap では、容器は取り出すまでスロットに残ります。インベントリからシフトクリックすると、空の容器は Out に、それ以外は In に入ります。

省略された数字にマウスを乗せると、全桁が見えます。

**バーをクリックする**と、表し方が切り替わります。選んだ表し方は人ごとに保存されます。

| 表し方 | バーが満杯になる量 |
|---|---|
| 割合（既定） | 容量 |
| 対数 | 容量。10倍ごとに目盛りが付きます |
| 桁の中 | 次の10の累乗 |

右上の**錠前のボタン**で、Heap を今の種類に固定できます。赤が Locked、灰色が Free です。固定した Heap は、空になっても種類を覚えていて、ほかの物は入りません。固定できるのは、中身が入っている Heap だけです。Energy Heap にはこのボタンはありません。

## Item Heap

画面を開かずに、置いたブロックに対して次の操作ができます。

| | |
|---|---|
| 入っているのと同じ物を持って右クリック | 持っているスタックを入れる |
| 入っているのと同じ物を持ってスニーク＋右クリック | インベントリにあるその物を全部入れる |

**同じ物の別の形も入ります。** 9個（または4個）で別の物1個に作れて、元にも戻せる組（金塊・金インゴット・金ブロックや、スライムボールとスライムブロックなど）は、どの形でも入ります。量は最初に入れた形で表示されます。パイプやホッパーが取り出すのもその形です。ほかの Mod の物も対象です。

**Out** の文字をクリックすると、Out スロットが一番小さい形に切り替わります。最初の形1個分に満たない端数（インゴットの Heap に入った金塊4個など）は、ここから取り出せます。

**持ち歩くと拾い集めます。** インベントリにある Item Heap は、入っている物を次のときに取り込みます。

- その物の上を歩いたとき
- ほかの方法でインベントリに入ってきたとき（少し後に取り込みます）

持ち歩いている Heap からは何も出ません。手に持っている物と身に着けた防具はそのままです。チェストなどの画面を開いている間は取り込みません。重ねて1スタックになった Heap は何も取り込みません。

空中に向かってスニーク＋右クリックすると、手に持った Heap の画面が開きます。空の Heap なら、ここで何を入れるかを決められます。拾い集めは設定の `absorbsWhenCarried` で止められます。

## Fluid・Energy・Gas Heap

Fluid Heap と Gas Heap は、ガラスの窓が中身の見た目で満たされます。

Energy Heap は、置いた人の方を向きます。正面には12個のランプがあり、容量までの桁を12個で分け合います。既定の容量なら、10倍ごとに1個ずつ点きます。10 FE で1個目が点き、1,000,000 FE で6個点きます。Energy Heap は、隣り合うブロックに電力を送ります。1ティックに隣のブロック1つあたり最大 1,000,000,000 FE です。

空中に向かってスニーク＋右クリックすると、手に持った Heap の画面が開きます。In スロットに置いた容器の中身は、持ち歩いている間も Heap に移せます。Out スロットには、持ち歩いている間は何も置けません。

## Horreum

どの種類の Heap でも、混ぜて9個まで入れられる棚です。つないだパイプやケーブルは、中のすべての Heap に届きます。アイテム・液体・電力・化学物質のどれでも同じです。

置いた Horreum は、置いた人の方を向きます。正面には、画面と同じ 3×3 の並びで棚ごとのランプがあり、入っている Heap の色で点きます。

| Heap | 色 |
|---|---|
| Item | 灰色 |
| Fluid | 青 |
| Energy | 琥珀色 |
| Gas | 緑 |

Horreum を壊しても、中の Heap はそのまま入っています。空中に向かってスニーク＋右クリックすると、持ち歩いている Horreum の画面が開きます。Heap の出し入れはできますが、Heap の中身は取り出せません。

## ツールチップ

Heap のツールチップには、入っている物と量が出ます。Horreum のツールチップには、中の Heap ごとに1行ずつ出ます。

## Mod を外したとき

Heap に入っている物を足していた Mod を外しても、Heap は中身を保ちます。ピンクと黒の市松模様と、入っていた物の ID が表示されます。その Mod を入れ直すまで、何も出し入れできません。

Mekanism を外しても、Gas Heap は同じように世界に残ります。作ることはできなくなります。

## Refined Storage

外部ストレージを Heap や Horreum に向けると、ネットワークから本当の量が見えます。2,147,483,647 個（または mB）を超えていても同じです。
