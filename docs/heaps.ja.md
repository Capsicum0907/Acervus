# 超容量ストレージと超容量ラック

[English](heaps.md) | 日本語

## レシピ

| ブロック | 材料 |
|---|---|
| 超容量チェスト | 鉄ブロック4個・ネザースター2個・ネザライトインゴット2個・チェスト1個 |
| 超容量タンク | 鉄ブロック4個・ネザースター2個・ネザライトインゴット2個・大釜1個 |
| 超容量蓄電器 | 鉄ブロック4個・ネザースター2個・ネザライトインゴット2個・レッドストーンブロック1個 |
| 超容量ガスタンク | 鉄ブロック4個・ネザースター2個・ネザライトインゴット2個・オスミウムブロック1個（Mekanism があるときだけ） |
| 超容量ラック | ネザライトインゴット4個・ネザースター4個・空の超容量ストレージ1個（種類は問いません） |

超容量ラックの材料にできるのは、空で固定していない超容量ストレージだけです。

## 画面

超容量ストレージを右クリックすると画面が開きます。入っている物・バー・量と容量・2つのスロットが並びます。スロットは左が **入** で右が **出** です。

| | 超容量チェスト | 超容量タンク・超容量蓄電器・超容量ガスタンク |
|---|---|---|
| **入** | アイテムを入れる | 置いた容器の中身を移す |
| **出** | アイテムを取り出す | 置いた容器を中身で満たす |

超容量タンク・超容量蓄電器・超容量ガスタンクの容器は、取り出すまでスロットに残ります。インベントリからシフトクリックすると空の容器は「出」に入り、それ以外は「入」に入ります。

省略された数字にマウスを乗せると全桁が見えます。

**バーをクリックする**と表し方が切り替わります。選んだ表し方は人ごとに保存されます。

| 表し方 | バーが満杯になる量 |
|---|---|
| 割合（既定） | 容量 |
| 対数 | 容量。10倍ごとに目盛りが付きます |
| 桁の割合 | 次の10の累乗 |

右上の**錠前のボタン**で、今の種類に固定できます。赤が「固定中」で灰色が「固定なし」です。固定すると空になっても種類を覚えています。ほかの物は入りません。固定できるのは中身が入っているときだけです。超容量蓄電器にはこのボタンはありません。

## 超容量チェスト

画面を開かずに置いたブロックへ次の操作ができます。

| | |
|---|---|
| 入っているのと同じ物を持って右クリック | 持っているスタックを入れる |
| 入っているのと同じ物を持ってスニーク＋右クリック | インベントリにあるその物を全部入れる |

**同じ物の別の形も入ります。** 9個（または4個）で別の物1個に作れて元にも戻せる組は、どの形でも入ります。金塊・金インゴット・金ブロックや、スライムボールとスライムブロックなどです。量は最初に入れた形で表示されます。パイプやホッパーが取り出すのもその形です。ほかの Mod の物も対象です。

「出」の文字をクリックすると、「出」のスロットが一番小さい形に切り替わります。最初の形1個分に満たない端数はここから取り出せます。インゴットを入れた超容量チェストに入った金塊4個などです。

**入れられない物があります。** 超容量ストレージと超容量ラック（空でも）・シュルカーボックス・バンドルと、中身ごと持ち出したチェストのように中身を持っている物です。空のチェストはほかのアイテムと同じように入ります。

**持ち歩くと拾い集めます。** インベントリにある超容量チェストは、次のときに中身と同じ物を取り込みます。

- その物の上を歩いたとき
- ほかの方法でインベントリに入ってきたとき（少し後に取り込みます）

持ち歩いている超容量チェストからは何も出ません。手に持っている物と身に着けた防具はそのままです。チェストなどの画面を開いている間は取り込みません。重ねて1スタックになったものは何も取り込みません。

空中に向かってスニーク＋右クリックすると、手に持った超容量チェストの画面が開きます。空ならここで何を入れるかを決められます。拾い集めは設定の `absorbsWhenCarried` で止められます。

## 超容量タンク・超容量蓄電器・超容量ガスタンク

超容量タンクと超容量ガスタンクのガラスの窓は、中身の見た目で満たされます。

超容量蓄電器は置いた人の方を向きます。正面には12個のランプがあり、容量までの桁を12個で分け合います。既定の容量なら10倍ごとに1個ずつ点きます。10 FE で1個目が点き、1,000,000 FE で6個点きます。

超容量蓄電器は隣り合うブロックに電力を送ります。送る量は1ティックに隣のブロック1つあたり最大 1,000,000,000 FE です。

空中に向かってスニーク＋右クリックすると、手に持ったものの画面が開きます。持ち歩いている間も、「入」に置いた容器の中身を移せます。「出」には何も置けません。

## クリエイティブ用の超容量ストレージ

クリエイティブ超容量チェスト・タンク・蓄電器・ガスタンクには、レシピがありません。クリエイティブのインベントリの Acervus のタブにあります。どれも入っている物をいくらでも出します。手で取ってもパイプで取っても減りません。枠は紫です。

| | クリエイティブ超容量チェスト | クリエイティブ超容量タンク・ガスタンク | クリエイティブ超容量蓄電器 |
|---|---|---|---|
| **入** | 置いた物を出す物として上書きします。置いたスタックは消えます | 容器の中身を出す物として上書きします。容器は空になります | 何も置けません |
| **出** | いくらでも取り出せます | 容器を満たします | バッテリーを充電します |
| パイプ | 求めた分だけ取り出せます | 求めた分だけ取り出せます | 求めた分だけ取り出せます |

外からは何も入りません。量は `∞` と表示され、錠前のボタンはありません。クリエイティブ超容量蓄電器はランプがすべて点き、超容量蓄電器と同じように隣へ電力を送ります。壊すと空のものが落ちます。超容量ストレージにも超容量ラックにも入りません。

## 超容量ラック

どの種類の超容量ストレージでも、混ぜて9個まで入れられる棚です。つないだパイプやケーブルは中のすべてに届きます。アイテム・液体・電力・化学物質のどれでも同じです。

置いた超容量ラックは置いた人の方を向きます。正面には棚ごとのランプが画面と同じ 3×3 の並びであります。ランプは入っているものの色で点きます。

| 入っているもの | 色 |
|---|---|
| 超容量チェスト | 灰色 |
| 超容量タンク | 青 |
| 超容量蓄電器 | 琥珀色 |
| 超容量ガスタンク | 緑 |

超容量ラックを壊しても、中の超容量ストレージはそのまま入っています。空中に向かってスニーク＋右クリックすると、持ち歩いている超容量ラックの画面が開きます。超容量ストレージの出し入れはできますが、その中身は取り出せません。

## 落としたとき

落とした超容量ストレージと超容量ラックは、火や溶岩で燃えません。溶岩の上ではネザライトのように浮きます。爆発やサボテンでも消えません。

ただし、ほかのアイテムと同じく、地面に5分置いたままにすると中身ごと消えます。それまでに拾ってください。

## ツールチップ

超容量ストレージのツールチップには、入っている物と量が出ます。超容量ラックのツールチップには、中の超容量ストレージごとに1行ずつ出ます。

## Mod を外したとき

中身を足していた Mod を外しても、超容量ストレージは中身を保ちます。ピンクと黒の市松模様と、入っていた物の ID が表示されます。その Mod を入れ直すまで何も出し入れできません。

Mekanism を外しても、超容量ガスタンクは同じように世界に残ります。作ることはできなくなります。

## Refined Storage

外部ストレージを超容量ストレージや超容量ラックに向けると、ネットワークから本当の量が見えます。2,147,483,647 個（または mB）を超えていても同じです。
